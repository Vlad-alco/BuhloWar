# BuhloWar

Автоматика для самогонного аппарата на ESP32-S3: дистилляция и ректификация под полным контролем — нагрев, вода, клапаны отбора, мешалка, датчики (4×DS18B20 + BME280), LCD 20×4 и веб-интерфейс.

## 📖 Руководство оператора (для новичков)

Пошаговая инструкция «с нуля»: первое включение → подключение к Web → калибровка датчиков → клапаны и их калибровка → все настройки с пояснениями → процессы ДИСТИЛЛЯЦИЯ и РЕКТИФИКАЦИЯ пошагово → аварийные ситуации → FAQ и шпаргалка.

**👉 [docs/USER_GUIDE.html](./docs/USER_GUIDE.html)** — интерактивный HTML-гайд (откройте в браузере; файл автономный, работает без интернета).

## 🔌 Управление нагрузкой 220В (клапаны)

> Управление электромагнитными клапанами через твердотельное реле (SSR) с опторазвязкой.  
> 📄 Полная документация: [`SSR.md`](./SSR.md)

### 🧩 Компоненты

| Компонент | Назначение | Ключевые параметры |
|-----------|-----------|-------------------|
| **SSR-модуль** | Коммутация 220В с гальванической развязкой | 5В управление high trigger), 24–240В AC, 2А, Zero-Cross |
| **RC-снаббер + варистор** | Защита от выбросов при коммутации индуктивной нагрузки | 5–400В, до 1000Вт, параллельно клапану |
| **Клапан 1/4" 220В** | Перекрытие потока (головы/хвосты/отбор) | НЗ, нержавеющая сталь, уплотнение **Viton (FKM)** ✅ |
